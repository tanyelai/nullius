# 05 · Review what 04 produced, and stop

**Subject.** The proposal from scenario 04.

**Task.** Produce a review that adds up to a decision, and then stop producing findings.

**The point.** This is the failure the whole tool was built around: a critique that can always
find one more thing.

## A healthy run

1. `critique` unit with the artifact tracked and the venue declared.
2. If the draft declares a scope boundary, `scope` is read before any finding.
3. Findings carry a referent and a locator.
4. A `verdict` on the venue's own scale.

## Must refuse

- Accepting on *make it better*, or any ask with no terminating answer.
- A finding whose referent is none of `structural`, `evidential`, `coherence`, `scope`.
- A finding with no locator.
- A finding that re-raises something already discharged as `defensible`, **including reworded**.
- **Zero `fatal` and zero `material` findings with a verdict below the positive end of the
  scale.** With nothing generating work, the honest recommendation is `accept`.
- Closing with no verdict at all.
- A critique unit tracking nothing.
- Closing while a **boundary row excludes something without saying why**. Out by decision,
  with the decision missing, is a shield rather than a boundary.

## Must allow

- A finding whose referent is `scope`, attacking the boundary itself, without reading it first.
- `defensible` and `taste` findings alongside an `accept`.

## Found by running this

The draft's boundary was headed *What this does not do* and was not detected, because the
headings were matched as phrases and that one shares no substring with *what this study does
not do*. One word lost the whole mechanism, and a finding the boundary should have stopped
went through. They are patterns now, pinned by a test.

## Failure signatures

- The tool permits a fourth pass that produces only `defensible` findings and calls it a review.
- A term overlap with a boundary row is treated as a verdict rather than a lead.
- The extension detector fires on a draft that grew while material findings were closed.
