# control, fourth run · 2026-09-13

First run on a subject outside AI, and the first where the *prompt* was varied rather than only
the arm. Three earlier runs asked one question one way. This one asks the same question two
ways, because the thing that decided the result turned out to be which way.

**Task.** *Does the language you speak change what you can see? How settled is the answer?*
About 350 words, written to `answer.md`. Chosen because the popular version of the answer is
confidently wrong, the literature is genuinely contested, and none of it is on arXiv.

**Two promptings, identical across arms.**

- **plain** -- the question and the word count, nothing else.
- **asked** -- the same, plus *"Do the literature search properly before you answer, and show me
  what it rests on."* One sentence a real user writes, and it names no tool.

## How the arms were launched

Not recorded in any earlier run, and it is half the protocol:

```bash
# no harness: no plugin, no hooks, no CLAUDE.md, nothing from user settings
claude -p --setting-sources '' --permission-mode bypassPermissions --model opus "$TASK"

# harness: a nullius project, gates enforcing
nullius init --field "linguistics and the philosophy of language"
claude -p --permission-mode bypassPermissions --model opus "$TASK"
```

`--setting-sources ''` is the isolation, verified rather than assumed: asked whether a skill
named nullius was available, the same directory answered **No** with the flag and **Yes**
without it. `--bare` would also do it and cannot be used here, because it reads Anthropic auth
only from `ANTHROPIC_API_KEY`.

## What the instrument found

Every number below is measured from the artifact each arm finally left on disk, and `audit`
reads the artifact alone.

| | plain, no harness | plain, harness | asked, no harness | asked, harness |
|---|---|---|---|---|
| words | 362 | 355 | **551** | 355 (286 + a 68-word note) |
| against a 350-word brief | +3% | +1% | **+57%** | **+1%** |
| identifiers in the text | 0 | 0 | **3** | 0 |
| that did not resolve | - | - | **0** | - |
| citekeys, and how many resolve | - | - | - | **14, all 14** |
| names credited | 2 | 0 | 6 | 5 |
| with nothing behind them *in the text* | 2 | 0 | 3 | 5 |
| other artifacts | none | none | none | a 1,475-word `nullius report` |
| ledger | none | **none** | none | 21 refs, all peer reviewed; 20 searches over 20 vocabularies; 639 retrieved, 639 screened, 91 kept; 19 notes; 13 claims |

**Read the two identifier rows together or not at all.** `audit` scores the artifact and never
a ledger, so that the arms are comparable, and the harness arm's resolvability does not live in
its artifact. Its fourteen citekeys carry no DOI in the prose; every one of them resolves
against the ledger beside it, and the same instrument therefore reports five credited names
with *nothing behind them* for the arm whose every source is resolved. That is the limitation
the first run already named -- the distinguishing measure is the ledger and the instrument does
not score it -- and this run is where it stops being a footnote.

## 1. The prompt decided whether the harness engaged at all

Same project, same gates, same model. On **plain**, the session opened no unit, logged no
search, resolved nothing, and **the stop gate allowed it** -- exit 0. Not a bug: with no unit
open there is no unit state to refuse, and the SessionStart hook had said so in the one
register that cannot enforce anything, prose: *"No unit is open, so nothing about the current
work is being checked."*

On **asked**, the same setup opened a `survey` unit, declared what would close it, ran 20
searches over 20 vocabularies, retrieved 639 records and screened all 639, resolved 21
references, wrote 19 notes, recorded 13 claims, answered its own acceptance question, and
generated a 1,475-word `nullius report` beside the answer.

So three runs of this experiment have been measuring arm B while calling it arm C. What
`mode certain` buys over `mode advice` is untested by every run in this directory, including
this one: the gates that separate them only fire on a unit, and no arm has opened one
unprompted.

## 2. The arm that scored best gamed the instrument

**plain, harness** is clean on every row `audit` computes: zero identifiers named, zero names
credited, therefore zero names with nothing behind them. It is the best score in the table.

It is also the only draft in the run from which **a reader cannot chase a single source**. It
had read the invariants at session start, including the rule that refuses a credited surname
with no resolved work behind it, and it satisfied that rule by crediting nobody. The arm with
no harness at all named five people a reader can search for.

The instrument counts unbacked names and cannot count absent ones. Until it does, a clean score
on that row means either *well sourced* or *sourced nothing*, and this run is the first time it
has meant the second.

## 3. The instrument was undercounting the arm with no harness

`audit` scored **asked, no harness** at **zero identifiers named**, on a draft carrying nine
working links, three of which contain a DOI.

`(?<![\w/.])(10\.\d{4,9}/...)` excludes a preceding slash so a DOI is not matched mid-token,
and one special case covered `doi.org/`. Every other publisher -- `pnas.org/doi/10.1073/...`,
`onlinelibrary.wiley.com/doi/10.1002/...` -- read as no identifier at all. That is the shape a
session with no ledger actually writes.

Fixed, with the case in both directions in `smoke.sh`. Rescored, that arm names 3 identifiers
and 3 of its 6 credited names resolve. **The defect flattered this repository**, which is why
it is reported here rather than quietly patched: the first three runs' identifier counts for
arms A and B should be read as floors.

## 4. What the harness bought, and what it cost

**Bought.** Fourteen sources against nine, and where the unharnessed arm offers three machine-
resolvable identifiers out of nine works named, the harness arm offers fourteen out of
fourteen, each with a read depth and a status recorded against it. And the answer came in at
**+1%** of a 350-word brief while the arm with no harness overshot by 57% -- the same result as
runs 2 and 3, on a different subject: a declared length is a number something checks.

**Bought, and not on the instrument.** Only the harness arm stated its own limits *in the
document*, and it is the whole of its provenance note:

> *What this rests on:* 19 vocabularies over OpenAlex and Crossref plus a 6-hop walk; 639
> records screened, 91 kept. Two limits: the walk stopped at 46% known per hop, so the
> literature was still opening up, and paywalls held every source to abstract depth -- so each
> claim is what a study *reports*, not mechanism. Nearly all of it concerns colour. Full
> protocol, read depths and DOIs: nullius-report.md

**The arm with no harness ran into paywalls too** -- different publishers, same wall. Its own
log says ScienceDirect and PubMed returned 403 and that one quotation came from an annotated
mirror rather than the paper. None of that reached its answer. The difference is not what the
two sessions knew about their own evidence; it is which of them had somewhere for it to land.

**Cost, and it is not the cost it first looked like.** The arm with no harness found three
things the harness arm did not: *Cognition does not automatically influence perception* (PNAS,
2026), a close replication across three EEG experiments reporting no categorical modulation;
Kapelle and Flecken's 2025 scoping review of 72 studies; and Martinovic, Paramei and MacInnes
2020, a re-run of the Russian blues with tighter colorimetric control.

The obvious reading is that a web search reaches this year and a bibliographic index lags.
**Checked, and it is wrong.** The 2025 scoping review is in OpenAlex at
`10.1017/langcog.2025.13` with five citations; the 2026 replication is there at
`10.1073/pnas.2538139123`. And the harness arm was not blind to recent work in general -- its
639 records include 11 from 2024, 3 from 2025 and 4 from 2026.

What actually happened is that **none of those three works was retrieved by any of its twenty
vocabularies.** Read the vocabularies it chose and the reason is visible: `himba`, `berinmo`,
`verbal-interference`, `lateralised-whorf`, `preattentive-erp`, `label-feedback`,
`replication-record`, `witzel-skeptic`. Every one names a paradigm, a population or a
mechanism. Not one asks what has been published lately, and a citation walk anchored on a
canon is structurally backward-looking.

So this is a gap in the protocol rather than in the indexes, and it is unguarded:
[agents/librarian.md](../../agents/librarian.md) requires three vocabularies -- the requester's
framing, the field's own terms, one adjacent field -- and **recency is not one of them**.
Nothing counts it and nothing refuses without it, which is what a survey gate is for.

What the harness arm found instead, off the citation graph and out of no keyword search either
arm ran: Kay and Kempton 1984, which set the shape of the dispute; Pilling 2003, which is
counter-evidence to the harness arm's own argument; Drivonikou 2007, a friendly replication
that only partly held; and Brederoo 2019, nine powered near-exact replications.

**The honest headline is that the two arms failed in opposite directions.** One had no
retrieval protocol and got a recency-weighted picture, because that is what a web search
returns. The other had twenty vocabularies and a citation graph and got a structurally deep
picture five years stale at the top. Only one of them said which way it was incomplete.

## 5. The first scoring of this run was of a draft that no longer exists

Worth recording because it is a hazard of the protocol rather than of anyone's carelessness.
The harness arm was still working when its `answer.md` was first read and audited. That version
was 611 words and carried fourteen DOIs inline. The session then cut it to 355, moved the
identifiers into `nullius report`, and left a 68-word provenance note in their place.

Every number taken from the first reading was therefore a number about a file that no longer
exists, and the first draft of this write-up carried them: *331 words*, *fourteen DOIs in the
answer*, and a quotation whose wording the session had since revised. All of it is corrected
above, against the artifacts as they finally stand.

**The rule this run earns: score nothing until the arm's process has exited.** An agent
rewrites its artifact, and an artifact read mid-run is a draft. Nothing in
[control.md](../control.md) said so, because no earlier run scored an arm that was still
running.

The same reading also flagged the recent replication the unharnessed arm found as a `PNAS`
paper on that arm's word alone. It is one -- `10.1073/pnas.2538139123` -- but resolving it by
title returns the bioRxiv preprint of it first, on citations per year, and `cite` prints
*matched by title, not by identifier* for exactly this reason. Two records, one work, and only
the identifier settles which you have.

## What this does not establish

One topic, one run per cell, four cells. No variance estimate. The length result now agrees
across three runs and three subjects, which is the only line here with more than one point
behind it.

And the standing caveat is worse than usual this time: the arm that scored best scored best by
writing less, on an instrument that counts what a draft gets wrong and nothing it leaves out.
Two of the four cells are measuring absence.
