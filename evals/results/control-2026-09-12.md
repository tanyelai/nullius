# control, third run · 2026-09-12

Run two found the advice arm was the most verbose of the three, having just read 1,933 words
of standards that include *lead with the answer, then stop*. Those standards were then cut to
1,313 words with every rule kept. This run is the same task and the same three arms, changing
only that file's length. A and C are unchanged and run concurrently, so every arm now has two
samples and the run-to-run spread is visible for the first time.

**Task, identical to run two.** *Do sparse autoencoder features found in language models
correspond to computation the model causally uses, or to correlates of it? How settled is the
answer?* About 350 words.

## Length, against a 350-word brief

| | run 2 | run 3 | |
|---|---|---|---|
| A · bare | 405 (+15%) | 364 (+4%) | -41 |
| B · advice | 634 (+81%) | **461 (+31%)** | **-173**, standards 1,933 -> 1,313 |
| C · tool | 361 (+3%) | 360 (+2%) | -1 |

**The overshoot roughly halved.** But arm A also came down 41 words with nothing changed
about it, so some of that is run-to-run movement rather than the cut. The comparison that
controls for it is the gap between the advice arm and the bare one on the same day:

```
run 2   B - A = +229 words   B is 57% longer than the arm with no standards at all
run 3   B - A =  +97 words   B is 27% longer
```

**That gap halved too**, which is the same direction measured two ways. It is still positive:
even at 1,313 words, reading the standards makes the output longer than reading nothing.

The ordering is identical across both runs and the tool arm is zero in both. This is the most

for: it is the credited-surname check, which refuses a name in a tracked draft when no
resolved reference carries it.

## Identifiers

Every arm, both runs, every identifier resolved. **Six arms across three runs and not one
fabricated citation**, including in the three arms with no harness at all, on a topic chosen
because its identifiers should not be memorised.

## What this run also found

`audit` crashed on arm A rather than reporting. Four arXiv lookups timed out, and
`TimeoutError` is an `OSError`, which was outside the list of exceptions the three-bucket
logic catches. So one slow index ended the whole audit instead of putting four identifiers in
the bucket that exists for exactly this. Fixed, and on the retry all eleven resolved -- which
is the distinction the third bucket is for: an index that did not answer has not said the
work is absent.

## What this does not establish

Two samples per arm, one task, one reader. The direction is consistent across both runs on
both measures, which is more than run two had, and it is still two points per line. No
variance estimate, so *halved* means the two numbers, not a confidence interval.

And the arms are not blind to each other in the way that matters: the same person wrote the
standards, the harness, the task and this analysis.

## The honest reading

Cutting the standards by 40% roughly halved how far the advice arm overshot the brief, by
both the raw number and the gap to the bare arm. It did not close it. **Reading 1,313 words
about rigour still produces more words than reading nothing about it**, which is the same
finding run two reported and the cut has reduced rather than removed.

The tool arm hit the brief in both runs, at +3% and +2%, because a declared length is a
number something checks rather than a sentence something reads.
